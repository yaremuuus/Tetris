# 🧱 Tetris — Классическая головоломка на Unity

Полноценная реализация легендарной игры Тетрис, написанная на движке **Unity 6** (URP) с использованием **C#**.  
Проект включает в себя все базовые механики, современный интерфейс, настройки сложности, систему рекордов и адаптацию под ПК.

---

## 🎮 Ключевые возможности

### 🧩 Игровой процесс
- Классическое управление падающими фигурами (стрелки / пробел)
- Система очистки заполненных линий с подсчётом очков
- Мгновенное падение и ускорение

### ⚙️ Гибкая система настроек
- **Регулировка скорости падения** (от 1 до 10)
- **Уровень сложности** — генерация «мусорных» строк от 0 до 12
- **Дополнительный пул фигур** (включается в настройках)
- **Фоновая музыка** с возможностью отключения

### 📊 Прогресс и сохранения
- **Система рекордов** — текущий счёт сравнивается с лучшим результатом и сохраняется между сессиями (используется `PlayerPrefs`)
- Отображение текущего счёта, уровня, скорости и рекорда в реальном времени

### 🎨 Интерфейс и управление
- Современный минималистичный дизайн
- Главное меню с кнопкой запуска
- Кнопки управления во время игры: **Play / Pause / Stop**
- Кнопка настроек (работает всегда: и в меню, и в игре)

## 🎮 Как играть

| Действие | Управление |
|----------|------------|
| Движение влево / вправо | Стрелки ← / → |

## 🏗️ Структура проекта (основные модули)

- `GridManager` — логика игрового поля, очистка линий, обработка блоков.
- `Figure` — управление активной фигурой (движение, вращение, коллизии).
- `FigureSpawner` — генерация новых фигур, превью новых фигур, управление уровнями (мусор).
- `GameController` — связующее звено между UI и логикой (старт/стоп/пауза).
- `SettingsManager` — управление настройками и их применение в реальном времени.
- `UIManager` — обновление счёта, рекорда и прочих UI-элементов.
- `AudioManager` — управление фоновой музыкой.
